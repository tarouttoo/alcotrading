# Проверка: бесплатный архив Bybit public.bybit.com (L2 по деривативам)

Ticket: «Проверка: бесплатный архив Bybit public.bybit.com (L2 по деривативам)»
(https://github.com/tarouttoo/alcotrading/issues/4, question → Q76: берём ли историю Bybit для бэктеста).
Дата проверки: 2026-11-12. Все выводы — по первичному источнику: листинги и файлы самого `public.bybit.com`.

## Вывод (коротко)

**L2-истории стаканов в бесплатном архиве Bybit НЕТ.** `public.bybit.com` содержит только сделки (trades), свечи (kline), premium index и spot index. Снапшотов orderbook / delta-обновлений L2 нет ни в одном разделе, ни по одному инструменту. Для Q76 это значит: **исторический L2 по Bybit для бэктеста взять неоткуда — только собственная запись стакана с нуля** (трейды из архива при этом можно использовать как дополнение).

## Что лежит в архиве (факты)

Корень `https://public.bybit.com/` — S3-листинг, ровно пять разделов:

- `trading/` — поминутные... нет, **подневные CSV.GZ со сделками** по деривативам (spot — в `spot/`).
- `kline_for_metatrader4/` — свечи для MT4.
- `premium_index/`, `spot_index/` — индексы.

Слово «orderbook» / «depth» не встречается ни в одном листинге разделов и файлов (проверено grep'ом по всем пяти разделам).

### Раздел `trading/` (USDⓈ-M деривативы)

- ~2151 директория: **~1144 USDT-перпетуала** (например `BTCUSDT/`) + директории квартальных фьючерсов вида `BTCUSDT-01AUG25/`, а также инверсные (BTCUSD и т.п.).
- Внутри пары: файлы `BTCUSDT2024-01-01.csv.gz` — один файл на день.
- **Формат** (заголовок файла): `timestamp,symbol,side,size,price,tickDirection,trdMatchID,grossValue,homeNotional,foreignNotional[,RPI]`; timestamp — секундный float (мс в дробной части). Пример строки: `1704067200.2353,BTCUSDT,Sell,0.002,42324.90,PlusTick,3b55416a-…`.
- **Период**: у BTCUSDT — с 2020-03-25 по вчера (2026-11-11 на момент проверки), ~2423 дневных файла, т.е. почти 7 лет. По молодым парам — с момента листинга.
- **Объём**: BTCUSDT за 2024-01-01 — ~850k строк, ~31 МБ в gzip. Свежие дни — до ~1.5M строк.
- Обновление — ежедневно (вчерашний день уже лежит).

### Раздел `spot/`

Месячные CSV.GZ (`BTCUSDT-2022-11.csv.gz`), тот же формат сделок, с 2022 года.

## Ответ на вопрос тикета

| Пункт вопроса | Ответ |
|---|---|
| Есть ли L2-история? | **Нет.** Только трейды/свечи/индексы. |
| Какие пары? | Все листинговые USDⓈ-M перпетуалы (~1144 USDT) + фьючерсы, но только trades. |
| Формат? | CSV.GZ trades (см. выше); L2 не существует ни в каком формате. |
| Глубина? | Неприменимо — данных нет. |
| Период? | Trades: BTCUSDT с 2020-03-25 по текущий день; L2 — нет. |

## Решение по Q76

Архив Bybit **не даёт** L2. Для бэктестов на L2 по Bybit — только собственная запись (websocket `orderbook.500` и т.п.) с нуля; бесплатный архив полезен как источник трейд-хистори для валидации/симуляции исполнений, но не стакана. Платные сторонние источники (Tardis и т.п.) вне рамок этого тикета.

## Источники

- `https://public.bybit.com/` — корневой листинг (5 разделов, L2 отсутствует)
- `https://public.bybit.com/trading/` — листинг пар деривативов
- `https://public.bybit.com/trading/BTCUSDT/` — дневные файлы 2020-03-25 … 2026-11-11
- `https://public.bybit.com/trading/BTCUSDT/BTCUSDT2024-01-01.csv.gz` — проверенный образец (формат, объём)
- `https://public.bybit.com/spot/BTCUSDT/` — месячные файлы спота
