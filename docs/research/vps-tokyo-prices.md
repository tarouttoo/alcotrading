## Рекомендация

**Vultr Cloud Compute `vc2-2c-4gb` в Токио — $20/мес.** Точное попадание в требования (2 vCPU, 4 ГБ, ровно 80 ГБ SSD), 3 ТБ трафика включено, самый дешёвый вариант шорт-листа, почасовая тарификация и быстрое развёртывание через API/Terraform. Диапазон хендоффа «$12–40» подтверждён: реальная нижняя граница для честных 2 vCPU/4 ГБ в Токио — ~$20; дешевле (nanode/1 vCPU или shared-CPU 2 ГБ) требованиям не соответствует.

Запасной вариант, если важно качество CPU и диска: Vultr High Performance AMD за те же $24 (NVMe, 100 ГБ, 5 ТБ). Если предпочтительны Linode/DO как экосистема — оба на $24, спецификации идентичны.

## Примечания и оговорки

- Vultr: поле `bandwidth` в API указано в ГБ (3072 = 3 ТБ); сверх лимита Vultr списывает по $0.01/ГБ (см. vultr.com/pricing —Cloud Compute). Регион Токио в списке `locations` плана (`nrt`).
- Linode `g6-standard-2`: 81920 МБ = 80 ГБ диска; трансфер по типу — 4 ТБ; подтверждено публичным API без авторизации. Бэкапы +$5/мес (не требуются по ТЗ).
- DigitalOcean: страница цен рендерит таблицу скриптом; строка «2 vCPUs, 4,000 GiB transfer, 80 GiB disk, $0.03571/hr» соответствует плану s-2vcpu-4gb (~$24/мес при 672 часах). Сверх трансфера DO берёт $0.01/ГБ.
- SAKURA (пункт 5): локальный японский провайдер, Токио-зона дороже Ишикари; включает 4 vCPU и 200 ГБ SSD — избыточно против ТЗ. Условия превышения трафика на странице тарифов не указаны — перед покупкой уточнить в договоре (сайт не раскрывает лимит). Цена с ежемесячной оплатой; годовая дешевле (~3,630 ¥/мес).
- AWS Lightsail в Токио **недоступен** (региона Tokyo нет в списке Lightsail) — не рассматривался.
- Hetzner не имеет региона в Токио/Японии — исключён.
- ConoHa (GMO): тарифная страница блокирует автоматический доступ (403), цену подтвердить по первоисточнику не удалось — не включён в шорт-лист.
