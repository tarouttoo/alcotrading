# Сырые сделки вместо агрегированных (переоткрытие Q44)

Q44 фиксировал «агрегированные сделки (aggTrade и аналоги), где биржа их
отдаёт». Замер 2026-11-12 (тикет #12) показал, что на Binance USDⓈ-M
фьючерсах `@aggTrade` не отдаётся: подписка принимается
(LIST_SUBSCRIPTIONS подтверждает), событий 0 в трёх попытках — при живом
спот-aggTrade (203 события) и живом сыром `@trade` (~50 событий/с на
BTCUSDT). Книга добавляет: aggTrades без VIP задерживаются (~100 мс),
alko для реконструкции цены настаивает на сырых trades. Bybit
`publicTrade` и OKX `trades` — сырые и так. Решение: пишем сырые сделки на
всех трёх биржах (`@trade`, `publicTrade`, `trades`) с нативными
идентификаторами (`t`/`seq`/`tradeId`); пропуск в ленте детектится
монотонностью id и пишется отдельным событием «пропуск сделок» (книга при
этом не инвалидируется).

## Considered options

- **Сохранить aggTrades** — отвергнуто: поток молчит на фьючерсах (замер),
  задержка ~100 мс без VIP; «где биржа их отдаёт» на Binance уже не
  выполняется.
- **aggTrades на Binance + «аналоги» на остальных** — отвергнуто:
  «аналоги» и есть сырые; смешанная семантика противоречит Q31
  (нормализованные события одного формата).
- **Сырые на всех трёх** — выбрано: сырой поток — надмножество информации;
  агрегирование при необходимости строится на верхних слоях, обратное
  невозможно.

## Consequences

- Объём записи растёт; оценка Q53 (15–25 ГБ/мес) перепроверяется суточной
  тестовой записью, резерв диска 80 ГБ.
- Исторической записи ещё нет — смена семантики сейчас бесплатна;
  осознанный пересмотр возможен после перепроверки с Токио (#10), если
  aggTrade оживёт.
- Перед первым коннектором перепроверить с VPS молчание aggTrade и живость
  сырых потоков (добавлено в #10).
