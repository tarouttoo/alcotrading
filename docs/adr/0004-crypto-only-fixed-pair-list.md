# Список 5 пар: только крипта, фиксация без пересмотра

Фаза 1 пишет пять одинаковых пар на трёх биржах (хендофф Q25/Q28), и точный
список — последнее открытое решение перед первым коннектором (тикет #8,
блокирует нарезку фазы #11). На дату решения (2026-11-12) в пересечение
трёх бирж по объёму входят не только криптовалюты, но и TradFi-перпетуалы —
токенизированные акции и сырьё (SOXL — №3 всего рейтинга, $8,4B/сутки
суммарно; далее SNDK, NVDA, XAU). Решение: в срез входят только криптопары;
якоря BTC, ETH, SOL; два «объёмных» слота отбираются по минимальному
суточному объёму среди трёх бирж с порогом ≥ $100M на каждой; итоговый
список **BTCUSDT, ETHUSDT, SOLUSDT, ZECUSDT, XRPUSDT** фиксируется на дату
решения без механизма пересмотра.

## Considered options

- **Буквальный «топ по объёму» без ограничения класса** — отвергнуто:
  TradFi-перпетуалы наследуют торговые сессии базового рынка, то есть
  систематические разрывы в круглосуточной записи; непрерывность данных
  важнее буквы критерия хендоффа.
- **Правило вместо фиксированного списка, вычисляемое на запуске** —
  отвергнуто: тикет требует точный список (он блокирует нарезку фазы),
  а механизм пересмотра размыл бы фиксацию.
- **Метрика «суммарный объём по биржам»** — отвергнута: худшая биржа
  ограничивает качество среза, так как каждая пара пишется на всех трёх
  сразу.

## Consequences

- После старта записи замена пары рвёт непрерывность данных по исключённой
  паре; пересмотр списка требует нового осознанного решения.
- Метрика «мин по биржам» и порог $100M/сутки остаются формальными
  критериями для любых будущих пересмотров.
